# 《哈基米模拟器》漫画开场 · 已接入版
当前接入版本：彩色线稿和平涂漫画。正式资源位于 `assets/cinematics/comic/`。

开场现已替代原先 3D 电影镜头。正式画面在 assets/cinematics/comic/，控制器与原场景入口保持兼容。约55秒，四页九格、十一段独白，自动播放并支持手动翻格/跳过。正式动画为分格揭示、画格内微小推近、字幕与页面淡入淡出、标题及音频，没有声称制作新的角色骨骼动画。

| 时间 | 画面 | 内心独白 |
|---|---|---|
| 0–3 | 黑幕淡开，陌生入口 | ……嗯？ |
| 3–9 | 猫眼高度望向陌生走廊 | 这是哪里？我怎么会在这里？ |
| 9–14 | 低头看白爪与尾巴 | 这双爪子……还有尾巴？ |
| 14–18 | 猫脸近景；首次切出播放一声喵 | 原来，我是一只猫。 |
| 18–24 | 观察房间 | 好大的房间。静得……只剩我的脚步声。 |
| 24–30 | 主人抚摸猫的额头 | 啊……我想起来了。我有一个主人。 |
| 30–35 | 门打开，猫迎接主人 | 我最喜欢她了。听见她回来，我就会跑过去。 |
| 35–41 | 主人生病，猫贴近无力的手 | 可是，她生病了。连摸我的手，都没什么力气。 |
| 41–45 | 回到现在，猫抬头 | 以前都是她照顾我。这一次，换我来。 |
| 45–49 | 下定决心 | 我记得……在这里，我就能学会照顾她。 |
| 49–55 | 向房间迈步、地垫旁纸条、标题 | 总之，先看看房间里有什么。 |

角色采用当前游戏的橘白虎斑外观。主人只出现手、衣袖和裤脚，不给出正脸、年龄或职业；无“人变成猫”的设定，也不提前透露实验室真相。

音乐和猫叫复用已有资源，无旁白配音。完成或跳过之后不再重复旧自述；第一天仍必须阅读地垫旁纸条才能解锁任务。继续存档不强制播放。

双击项目根目录“预览漫画开场.cmd”或在编辑器打开 scenes/cinematics/OpeningPreview.tscn 按 F6。预览不读写玩家正常存档。正式新游戏从主菜单进入。
完整使用与调节说明见 [漫画开场说明](../assets/cinematics/comic/README.md)。
