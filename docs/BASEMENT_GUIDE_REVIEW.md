正式游戏已使用新控制盒、格栅和笼牌；第十一天可通过 report 读取举报材料，通过装置的额外入口查看终端。原三个选择和原逃生流程保留。平视笼门锁扣时优先开关门，低头看旧抓痕时优先调查证据，避免证据代理抢走关门操作。
