# 猫屋日记
用 Godot 4.7.1 开发的三花猫第一人称探索游戏。当前地图为按审阅 V1 平面图建设的两层独栋别墅及花园，已完成家具与生活陈设布置。

## 开始

在其他电脑上，安装 Godot 4.7.1，导入本仓库中的 **project.godot**，完成首次资源导入后按 **F5** 运行游戏。

双击 **开始游戏.cmd**，点击「开始游戏」。双击 **打开编辑器.cmd** 可继续在 Godot 中编辑。启动器使用 C:\zGoDot\Godot_v4.7.1-stable_win64.exe，同时兼容最初提供的 C:\GoDot 路径。

启动页只保留游戏标题和开始、设置、退出三个按钮，背景使用房屋实景。设置包含音量和全屏；完整操作说明放在暂停页。游戏内左上角显示小地图与当前位置，底部保留简短快捷键，房门提示仅在可互动时出现；已删除重复标题、房屋说明和角色眼高信息。

界面预览：[启动页](previews/ui/main_menu.png)、[游戏内界面](previews/ui/hud.png)。

Git 同步时，`.godot/` 中的导入缓存、着色器缓存和编辑器状态由各电脑自行生成，已通过 `.gitignore` 排除。请保留脚本和着色器旁的 `.uid`，以及图片、音频旁的 `.import` 文件：前者保存稳定的资源标识，后者保存导入设置。不要添加 `*.gd.uid`、`*.uid` 或 `*.import` 这样的忽略规则，也不要把它们统一执行 `git rm --cached`。

| 按键 | 操作 |
| --- | --- |
| WASD、鼠标 | 移动、环顾 |
| 空格 / Shift / Ctrl | 跳跃 / 奔跑 / 低伏 |
| Q / V | 喵叫 / 查看三花猫 |
| E | 靠近并看向房门，打开或关闭 |
| M | 打开或关闭当前楼层地图，Esc 也可关闭地图 |

| 总览中的 1 / 2 / 3 | 展开一层 / 展开二层 / 完整房屋 |

| Esc | 暂停、音量与返回入口 |

## 本次房屋主体

- 用地 **22×28 米**，房屋主体 **12×12 米**，层高 **3 米**。
- 一层：客厅、餐厅、厨房、客卧、卫生间、洗衣间及过厅。
- 二层：主卧、两间次卧、书房、卫生间、衣帽储物区、阅读角及 **12㎡露台**。
- 楼梯和湿区上下对齐；楼梯具有实际的 **18 级踏步**及半层平台，二层楼板保留楼梯开口。
- 花园：北侧庭院及木平台、前后贯通的两侧小径、南侧入户庭院、车位铺地与外围边界。
- 已完成墙体、门洞、窗框玻璃、楼板、屋顶、露台栏杆、踢脚线与基础灯光。
- 默认采用清晰日间光照，降低均匀环境补光，关闭 SSIL、雾和泛光，减轻画面泛白。室内反射探针为金属与釉面提供房屋环境反射。
- 木板、木纹、亚麻、灰泥和矿物石材使用 1024 像素细节贴图，含高度及粗糙度信息；启用 mipmap 和 16 倍各向异性过滤，减少低视角细纹闪动。
- 各房间采用独立墙面、地面和软装配色，取消全屋统一的护墙色带。厨房为深鼠尾草绿，卫浴为蓝绿瓷砖，书房为深绿与深木地板，卧室分别采用蓝灰、灰紫、陶土与橄榄色。
- 墙体和踢脚线保留连续合并网格，清除接缝和端面重叠；门窗套、屋檐、石材墙脚、排水管和入户雨棚仍保留。
- 共 **19 扇可开关门扇**（含双开门），具备实际碰撞及遇猫暂停机制。靠近并看向门或打开后的门洞，按 **E** 操作。
- 其中 **9 扇门扇默认敞开**，对应厨房、书房、洗衣间、衣帽间和露台；卧室、卫生间及入户/花园外门默认关闭。走廊增加 10 块小门牌。
- 花园树木采用渐细分枝、独立立体叶片与根部细节，种植槽添加观赏草；小径改为连续铺地。
- 落地镜及镜面摄像机已移除。
- 现有 20 种家具和 24 种生活资产，共 163 个家具陈设实例及 10 块门牌，按房间用途摆放在客餐厅、厨房、四间卧室、书房、卫浴、洗衣间、阅读角、露台与花园休息区。
- 新增窗帘、地毯、挂画、电视、台灯、餐具、盆栽、淋浴角、洗衣机与收纳等，全部独立保存在 [furniture_pack](furniture_pack/使用说明.md)。详见 [房屋布置说明](furniture_pack/房屋布置说明.md)。

世界以米为单位。游戏中的猫统一缩小至原来的 **80%**，模型、碰撞体、眼位及第一人称前爪同步调整，正常眼高约 **22.4 厘米**。高精度猫网格和 47 根骨骼仍保留，独立猫模型工作室保持原始建模尺寸，详见 [模型说明](MODELING.md)。

左上角小地图随猫的朝向旋转，一层、二层、楼梯和花园自动切换。M 打开完整地图时停止移动，M / Esc 关闭后恢复；地图与暂停、看猫和房屋总览互斥。地图资源位于 `villa_maps/`，支持仓库刚拉取、图片尚未生成本机导入缓存的情况，详见 [地图说明](villa_maps/README.md)。

猫使用直立、单位缩放的胶囊碰撞体（半径 0.096 米、高 0.288 米），运行时也会修正意外的旋转或缩放。楼梯仍由真实踏步提供碰撞；摄像机对台阶高度作短暂平滑，蹲伏时限制最低视线，避免贴进踏步。修改猫大小请使用 `cat_scale`，不要旋转或拉伸碰撞节点来调整体型。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| scenes/main.tscn | 当前游戏主场景 |
| scenes/villa.tscn | 可直接编辑的完整两层别墅与花园 |
| scripts/villa_builder.gd | 按 V1 平面图生成房屋主体 |
| scripts/villa_furnishings.gd | 各房间家具、设备与生活陈设的位置和朝向 |
| furniture_pack/scenes | 44 种可复用家具、陈设及门牌场景 |
| furniture_pack/textures | 木纹、织物、灰泥及矿物材质细节贴图 |
| furniture_pack/room_finish.gd | 房间软装配色，不修改共享的原始家具材质 |
| shaders/villa_interior.gdshader | 按房间位置区分内墙、特色墙与瓷砖 |
| shaders/villa_finish.gdshader | 地面及收边的纹理、凹凸与粗糙度 |
| shaders/villa_surface.gdshader | 分离材质底色与纹理细节，保持自然配色 |
| scripts/villa_game.gd | 楼层识别、房门交互与房屋总览 |
| scripts/villa_door.gd | 门扇开关动画、碰撞与遇猫暂停 |
| scripts/villa_geometry.gd | 合并墙体及收边，去除重复表面 |
| scripts/villa_foliage.gd | 分枝、立体叶片与观赏草 |
| scripts/player.gd | 猫视角、控制、踏步通行与小体型尺度 |
| scripts/house_builder.gd | 新版别墅共用的基础网格与材质工具 |
| scripts/game.gd | 新版游戏共用的控制、音效与看猫功能 |

在 Godot 中运行主场景即可探索；展开场景树中的 Apartment/GroundFloor、UpperFloor、Staircase、Roof、Garden 可分别编辑。房屋由实际网格、材质和物理碰撞组成，不依赖外部建模插件。

重新生成房屋：

```powershell
& 'C:\zGoDot\Godot_v4.7.1-stable_win64_console.exe' --headless --path . --script res://tools/build_villa.gd --log-file "$env:TEMP\cat-villa-build.log"
```

通行验证：

```powershell
& 'C:\zGoDot\Godot_v4.7.1-stable_win64_console.exe' --headless --path . --script res://tools/playtest_villa.gd --fixed-fps 60 --log-file "$env:TEMP\cat-villa-playtest.log"
```

验证覆盖 19 扇门的开闭碰撞、两侧 E 交互、遇猫暂停及恢复、16 处门洞的实际通行、18 级楼梯的完整上下行、楼板与玻璃碰撞、猫的缩放，以及房屋总览和暂停恢复。房屋截图统一使用 `tools/capture_furnished.gd`。

`tools/validate_furnished.gd` 检查家具实体重叠、门扇完整开启范围和所有房间的猫通路；`tools/capture_furnished.gd` 拍摄已布置房屋的 15 个视角。房屋家具在 `GroundFloor/Furnishings`、`UpperFloor/Furnishings` 和 `Garden/Furnishings` 中按房间分组。重新生成房屋会同时恢复代码中定义的家具布置，覆盖场景中的手工位置修改。材质与配色调整见 [材质与房间风格](furniture_pack/材质与房间风格.md)。

## 目录整理约定

`assets/`、`scenes/`、`scripts/`、`shaders/` 保存游戏资源；`furniture_pack/` 保存可复用家具及其材质、原始几何和生成工具；`villa_maps/` 保存运行时地图及原始图层；`tools/` 保存生成和验证工具。猫的建模源数据和可编辑 GLB 均保留。

预览仅保留两个家具总览、四张房间示例以及当前界面的两张图。单件缩略图、更多房间截图和地图调试截图可通过对应捕获工具重新生成。日志、临时检查图和本机编辑器缓存不属于游戏内容，后续无需提交。
