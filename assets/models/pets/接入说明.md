# 新猫与楼梯平台犬

已在当前工程接入用户提供的两个 GLB，原始 `C:/zGoDot/3D` 文件未改动。猫保留来源模型的橘白花色。

## 资源与尺寸

- `house_cat.glb`：猫，8,646 个三角面、39 骨骼；保留原 UV、贴图与眨眼形变。
- `cat_forepaws.glb`：从同一猫的前腿网格和原骨骼提取的第一人称前爪，保留腕部与脚趾。
- `landing_dog.glb`：犬，14,844 个三角面、45 骨骼；伏卧、闭眼、呼吸，喂食后摆尾。
- `authoring/cat.blend`、`authoring/dog.blend`：可继续编辑的 Blender 文件，纹理已打包。
- GLB 导入后同目录的 PNG/JPG 是材质依赖，应一并同步；它们不是 `.godot` 里的临时缓存。
- 猫的规范肩高 0.32 m，游戏缩放 0.8，实际 0.256 m；犬规范肩高 0.64 m，同样缩放 0.8，站立参考为 0.512 m。两倍指线性参考尺寸，不是伏卧后的屏幕高度。
- 坐标为 Godot Y 向上、朝向 -Z，单位米。第一人称前爪使用独立的透视显示缩放，避免贴近镜头时占满屏幕；角色本体尺寸不受影响。

## 动作与控制

猫的九段 Blender 骨骼动作：idle、walk、run、crouch、jump、stretch、sit、tailwag、meow。运行时按实际移动速度切换与交叉淡化；跳跃收腿按垂直速度同步，不另行驱动角色位置。加入眨眼，修正源模型悬空的胡须位置。

猫的动作已改为稳定弯曲平面的保长关节解算，缩短步幅并保留原骨骼滚转角，不再强行拉长远端关节。平滑躯干和四肢的权重过渡，坐姿的脊柱倾斜分摊到多节骨骼；脸、耳和尾部保留原权重。开场转头每帧先恢复基础旋转，再叠加一次有限偏转，避免转头累计到后续游玩。身体与第一人称前爪使用同一批重新烘焙的动作。

`scenes/calico.tscn` 保留原场景入口名称，现改为新 GLB 的兼容包装，玩家、模型预览和开场使用同一只新猫。`scripts/imported_cat.gd` 保留原控制接口，`scenes/cat_forepaws.tscn` 负责前爪。第一人称眼高按新模型调整至约 32 cm；碰撞胶囊与移动输入保留。

`scripts/player.gd` 的 `jump_speed` 从旧值 5.25 改为 4.75；空地实测起跳高度约 0.98 m。可以在玩家节点 Inspector 继续微调。前爪在起跳中前伸、收腕，落地收回；低头查看仍可显示。

## 狗窝与原任务

`furniture_pack/scenes/dog_nest.tscn` 是可复用的完整狗窝场景，配套模型与 Blender 源文件分别在 `furniture_pack/models/dog_nest.glb` 和 `furniture_pack/authoring/dog_nest.blend`。床底为直径 1.10 m 的圆形木底与软垫，置于一二楼之间 1.50 m 高的平台中央，世界位置为 (4.60, 1.50, -1.41)。碰撞也使用圆柱体。

平台平面范围为世界 X=3.45–5.75、Z=-2.32–-0.50。两段楼梯仍有 18 个等高真实台阶，踏面深度约 22.2 cm，首尾出口不变。狗窝两侧保留通道，南侧转弯线为 Z=-0.71；已检查 30/60/120 Hz 上下楼双向通行。小地图同步实际平台、踏步和狗窝位置。

犬的休息动作在原 45 骨骼上重新烘焙。躯干轻弯，头部放低，四肢使用固定弯曲平面和保长两段关节解算，末端不可达时不强行拉长骨骼。原尺寸、闭眼、呼吸和喂食摆尾保留。

项目目前有第一、二天剧情和喂食任务。第二天原球体犬改为引用这只平台犬的交互点，不再重复生成旧犬。既有叼碗、喂食、饱腹值与洗盘任务保留；喂食会使新犬摆尾。

## 修改入口与重新导出

1. Blender 打开 `authoring/cat.blend` 或 `authoring/dog.blend`，在动作编辑器选择动作。
2. 自动制作脚本为 `tools/prepare_imported_pets.py`。为避开 Blender 连续清空场景时的崩溃，每种动物使用独立进程运行，参数为 `-- --kind cat` 或 `-- --kind dog`。
3. 狗窝源脚本为 `tools/build_dog_nest.py`。家具应保存回家具文件夹。
4. Godot 导入 GLB 后，`tools/build_villa.gd` 可重建含狗窝的房屋。原 `build_cat.gd`、`export_cat.gd` 在新模型存在时不会重新覆盖为旧程序猫。
5. `scenes/cat_studio.tscn` 可 F6 查看新猫各姿态、骨骼和灰模；主场景 F5，V 切换第三人称，空格跳跃，Q 猫叫。
