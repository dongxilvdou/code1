# 哈基米模拟器 · 漫画开场

2026-10-23。采用用户最后选定的彩色线稿与平涂样页，替代原 3D 开场。

## 播放

- 主菜单“新游戏”播放；“继续游戏”沿用存档流程。
- 双击项目根目录 `预览漫画开场.cmd` 可单独预览；预览场景禁用保存，不会重置正常存档。
- Godot 编辑器打开 `scenes/cinematics/OpeningPreview.tscn`，按 F6。
- 默认自动播放约 55 秒。空格、Enter、E、点击画面或左下角按钮进入下一格；Esc / 右下角按钮跳过整个开场。
- `OpeningCutscene` 节点可配置 `autoplay`、`allow_advance`、`allow_skip`、`playback_policy`。修改在本过场内生效，不增加全局输入映射。

音频复用 `assets/audio/opening_dawn.wav` 和 `assets/meow.wav`。背景音乐循环并淡入淡出，猫叫只在指定画格首次切出时播放一次；没有旁白、咳嗽或新录制音效。

## 调整

1. `opening_book.json`：编辑 `cues` 的时间、正文、页号、画格号、文字位置和宽度。位置与多边形顶点使用相对页面的 0–1 坐标。`meow: true` 所在段触发唯一一次猫叫。
2. `pages`：更换图片路径，调整画格多边形；`start/end` 控制整页淡入淡出的时段。新页也要添加对应的 `cues`。
3. Godot 打开 `scenes/cinematics/OpeningCutscene.tscn`，选择 AnimationPlayer 的 `opening`。目前 55 秒时间轴线性驱动 `film_time`。若改变总时长，同步更新动画长度及末帧、JSON 的页尾/时长，以及控制器末尾淡出与标题的时间。
4. 颜色、字幕字体与按钮样式在该场景和 `scripts/cinematics/opening_cutscene.gd` 中。画格贴图和轻微推近逻辑在 `scripts/cinematics/comic_panel.gd`。

## 接入与保留

漫画期间暂停角色输入与物理处理，保留真实角色的位置、骨骼、摄像机和全局灯光。退出时统一恢复状态；在黑幕下让第一天初始化真实出生位置，再淡入游戏。完成或跳过后通过会话标记抑制旧的六段重复自述，原“读完当日纸条才能开始任务”的逻辑保留。

当前 3D 猫、地图、门、家具、任务道具及存档格式均沿用。旧开场脚本和场景已备份在项目外 `C:/zGoDot/backups/Cat_before_comic_intro_20261023/`。旧生成工具被保护，避免再次覆盖漫画场景。

插画使用内置 image_gen，基于用户所选彩色样页生成，保存为项目内正式资源；没有外部临时路径依赖。制作提示词留档于 `design/opening_comic_v1/production/`（该设计文件夹不进入 Godot 导入）。
