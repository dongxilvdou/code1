# 次卧桌下的红色按钮

位置是二楼次卧 A 的书桌底部。次卧 B 已是电脑房，不改动它。
靠近桌前膝部空间、抬头看按钮，按 E 显示“可能有精神污染，请勿随意触摸”；
再按 E 或点击“再次按下”才开始，Esc 可在任意阶段取消。

房门先关闭，再熄灭灯光和房内自发光灯罩。独立摄像机选取床边无遮挡位置，
猫保持原位；床上方播放扣除绿幕的视频约 6 秒，保留少量冷色环境光以看清轮廓。
声音提高到源音轨的 1.4 倍并限幅。结束后恢复进入前的房门、灯光、材质、
摄像机、界面及鼠标控制，不写入任务或存档状态。

双击项目根目录的 `预览次卧彩蛋.cmd` 可直接试按钮。预览不会读取或覆盖正常存档。

- 控制器：`scripts/cinematics/bedroom_secret.gd`，主场景的 `BedroomSecret` 节点。
- 按钮独立资源：`furniture_pack/scenes/hidden_red_button.tscn`。
- 视频：`cat_sway.ogv`，项目内可直接播放，不依赖开发电脑原视频路径。
- 绿幕：复用 `shaders/dog_secret_key.gdshader`，平面始终朝向观看摄像机。
- 时长及房间引用可在 `BedroomSecret` 节点调整。
- 原始视频不修改。重制时运行 `tools/build_bedroom_secret_video.py --ffmpeg <FFmpeg路径>`。
- 狗窝修正：扩大前侧低入口、对准前爪并重新居中狗模型；保留原尺寸、骨骼和碰撞体。
- 修改前狗窝源文件已备份到项目外 `C:\zGoDot\backups\Cat_before_bedroom_secret_20261024`。
