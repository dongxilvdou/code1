# 客厅电视与厨房香蕉彩蛋

- 客厅电视下方有带电源符号的开关，靠近看向开关按 E。
  现有电视屏幕播放“新鲜哥”约 5 秒后自动关机，再按开关也可提前关机。
- 厨房北侧、冰箱旁的空台面放了一根香蕉。跳上台面后看向它按 E，
  香蕉暂时替换为“昏睡流口水香蕉猫”约 5 秒，结束后香蕉恢复。
- 视频去除绿幕，香蕉投影朝向当前玩家视角。新着色器按绿色色相抠像，
  保留黄色香蕉皮，不改动之前的大狗与次卧彩蛋。
- 期间可以正常移动和转动鼠标。暂停、进入剧情或切换观察模式时立即停止并复原。
  不改写任务、背包或存档；声音按距离衰减，沿用游戏主音量设置。

原始 MP4 保持不变，项目内 OGV 可独立运行：

- `fresh_cat.ogv`：新鲜哥（有声）.mp4 前 5 秒，960×540、30 fps。
- `banana_cat.ogv`：昏睡流口水香蕉猫（有声）.mp4 前 5 秒，
  原视频裁剪 `2400:1440:800:480`，缩放到 800×480、30 fps。
- 编码：Theora 质量 7、Vorbis 质量 5，音频限幅 0.95。

独立控制器：`scripts/cinematics/house_memes.gd`，主场景 `HouseMemes` 节点。
电视与台面使用现有家具引用；`play_seconds` 可调整时长。
开关与香蕉存放在 `furniture_pack/scenes/`，香蕉保留 Blender 源文件、UV 贴图与 GLB。
`tools/build_house_meme_props.py` 可通过 Blender 重新生成香蕉。

花园声音核对：实际播放源只有一条夏日录音，无叠加旧雨声；已降低之前过高的增益，
并对录音做轻度固定底噪抑制，保留室内外平滑音量切换。详见 `assets/audio/summer_afternoon.md`。
