# 阿嚼的秘密能力

2026-10-24。独立可选彩蛋，不改变任务、道具、地图、输入映射或存档格式。

## 正常触发

阿嚼已经搬到厨房（第六天放行后及后续天数），每次**普通闲聊结束后**独立掷一次 50% 概率。先完整显示原本对话；喂食、交物品、放行和第十天的关键老鼠剧情保持优先，不掷彩蛋。未触发时直接恢复普通游戏；触发时进入七段独立对话，猫多次请求后阿嚼才同意。

阿嚼第一句严格为：“曾经的我有一个能力，威能巨大，我不敢轻易尝试”。E / 空格 / Enter 或按钮推进彩蛋对话。Esc 可随时退出彩蛋，防止被困在播放状态；退出与自然结束共用恢复流程。

## 演出

1. 对话后用约 0.8 秒压暗环境。实际 Light3D 灯光归零；吊灯灯面、发光材质和不受光照材质使用临时暗色副本，一起熄灭。原材质不修改。
2. 在狗的头部骨骼正上方约 0.95 米悬浮一张 1.6 × 0.9 米平面，实时抠掉绿幕；始终朝向玩家的临时观看摄像机。平面无碰撞，不改变原狗的骨骼与碰撞。
3. 只播放原视频的**前 6 秒**，音量乘 1.4（约 +2.9 dB），增加 0.95 限幅。
4. 结束后立刻全白，保持 **3 秒**，随后约 3 秒逐渐恢复视野。
5. 恢复全部灯光、发光面原引用、HUD、摄像机、鼠标、玩家输入/物理处理和狗的处理状态。演出期间原任务不会继续计时，玩家的位置、物品和任务进度不受彩蛋修改。

没有修改全局渲染配置或永久关闭任何灯。环境覆盖只属于临时摄像机。背景音临时压低，结束恢复。概率使用自己的随机数生成器，不扰动地图或其他随机逻辑。

## 媒体与维护

原素材来自用户指定的本地 MP4，原文件保持原样。Godot 运行时只依赖项目内 `dog_power.ogv`，可随项目同步，其他电脑不需要该绝对路径、FFmpeg 或 Python。

转码：Ogg Theora / Vorbis、960×540、30 FPS、6 秒。实时抠像及溢绿处理见 `shaders/dog_secret_key.gdshader`。此方式依据 [Godot 视频播放文档](https://docs.godotengine.org/en/stable/tutorials/animation/playing_videos.html)。工具 `tools/build_dog_secret_video.py --ffmpeg <ffmpeg.exe路径>` 可重建资源与校验清单。

脚本：`scripts/cinematics/dog_secret.gd`。场景入口仅在 `scenes/main.tscn` 增加 `DogSecret` 节点；普通闲聊钩子分别位于 `act3/chapter.gd`、`act4/chapter.gd`。

独立预览：双击项目根目录 `预览大狗彩蛋.cmd`。它创建临时第八天会话并把概率设为 100%，便于查看，**不读取或写入正常存档**。正式游戏默认仍是 50%。

实机图保存在忽略提交的 `logs/dog_secret/`。项目原有退出时 ObjectDB / 资源释放提示仍在，未声称消除这些与彩蛋无关的退出提示。音量已做约 +2.9 dB 增益与限幅，最终听感可用游戏原有音量设置调整。
