# 工作书房、电脑房与地下室楼梯

2026-10-17，单位为米，沿用原别墅布局及 0.8 倍猫咪比例。

## 已完成

- **一楼原客卧 → 工作书房**：撤下床、床头柜和衣柜，摆放 1.8 m 工作桌、椅子、书架、阅读椅、边几、台灯和绿植。桌面包含 A4 图纸、30 cm 刻度尺、铅笔、签字笔、笔记本、橡皮、螺丝刀和小锤。
- **二楼次卧 B → 电脑房**：保留房间面积，撤下卧室家具，布置双 27 英寸显示器、键盘鼠标和桌垫、三风扇台式主机、双音箱、头戴耳机及支架、路由器和插排，配可调式办公椅。次卧 A、主卧和二楼原书房保留。
- **一楼楼梯口右侧 → 地下室楼梯**：与原上楼入口并排，从原楼梯下方下降，18 个真实台阶，踏步高 0.15 m、深 0.20 m，净宽约 1.08 m。下层标高 -2.70 m，设转身平台、扶手和暖光壁灯。底部为后续地下室的预留平台，本次未扩建完整地下室房间。
- **公共区域桌面餐具清理**：原盘子和筷子实际位于客厅旁的餐厅大桌，本次移除四套餐具实例；客厅茶几书本、花瓶及餐厅水果保留，家具库中的可复用餐具资源保留。
- 门牌、门的交互名称、房间识别和地图名称已更新；增加地下层地图和一楼 B1 入口提示。旧地图房间 ID 维持不变，避免影响已有任务进度。

## 新家具资源

全部通过本机 Blender 5.2.2 Python 建模，导出 glTF 2.0，再包装为 Godot 可复用场景。

| 场景 | 内容 |
|---|---|
| `scenes/work_desk.tscn` | 木面工作桌、金属桌腿、横梁和理线槽；桌面高约 0.778 m |
| `scenes/drafting_kit.tscn` | 纸笔、尺子、切割垫及简单工具，整体约 0.63 × 0.40 m |
| `scenes/dual_monitor.tscn` | 双屏及金属支架，宽约 1.245 m，带简洁桌面界面纹理 |
| `scenes/keyboard_mouse.tscn` | 独立键帽、掌托、鼠标滚轮和桌垫 |
| `scenes/computer_tower.tscn` | 主机、散热风扇、状态灯、USB 和电源键 |
| `scenes/audio_accessories.tscn` | 一对音箱、耳机和支架 |
| `scenes/router_power.tscn` | 双天线路由器和插排 |
| `scenes/office_chair.tscn` | 五爪脚轮、座垫、腰背支撑、头枕及扶手 |

上述路径均相对 `furniture_pack/`。对应 GLB 位于 `models/`，完整尺寸及内容索引为 `workrooms_catalog.json`。Blender 源文件为 `authoring/workrooms.blend`，各模块分开排列，可继续编辑；该文件夹有 `.gdignore`，防止重复自动导入建模源文件。

桌面、桌腿、办公椅和主机有简化碰撞。纸笔、键帽等小细节不单独制造大量碰撞体。电子设备目前作为室内陈设，屏幕为静态装饰界面。

## 修改位置

- `scripts/villa_furnishings.gd`：两个新房间的实例布局、移除公共区域餐具。
- `scripts/villa_basement.gd`：楼梯、平台、挡土墙、扶手和照明，以及各地面层的真实开洞。
- `scripts/villa_builder.gd` / `scenes/villa.tscn`：房间门牌、第二个楼梯入口和地下层场景。
- `furniture_pack/room_finish.gd` / `shaders/villa_interior.gdshader`：书房暖绿与电脑房蓝灰配色。
- `scripts/player.gd`：将原来固定 -2 m 的跌落复位阈值改为可导出参数；主场景中设为 -7 m，以允许正常进入地下层。移动、跳跃、摄像机和输入映射保持原有方式。
- `scripts/villa_game.gd`：地下层房间识别及总览时的层显示。
- `villa_maps/layout.json` / `map_hud.gd` / 对应地图图层：新名称、B1 图层及自动切换。

后续只同步 `scenes/` 不足以包含这次修改，也需要同步上述脚本、家具模型与场景、材质及地图资源。`.godot/` 仍是本地缓存。
