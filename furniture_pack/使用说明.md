# 可复用家具与道具资产库

此目录保存《哈基米模拟器》的家具、陈设、任务道具和地下室资产。正常游戏已在别墅中实例化这些资源，独立预览仅用于查看和继续制作。

## 查看与使用

双击 `预览家具.cmd`，或在 Godot 打开 `preview.tscn` 按 F6。左侧列表/左右方向键切换物品，左键拖动和滚轮调整视角，R 复位；G 查看总览，H 隐藏界面，Esc 退出。

[家具库总览](previews/catalog.png) · [陈设库总览](previews/catalog_decor.png)

从 `scenes/` 拖入单件资源，或复用现有场景中的实例。单位为米，Y 向上，家具正面一般朝 +Z，根节点放在地面或台面。原始建模尺寸见 [家具尺寸](尺寸清单.md) 和 [陈设尺寸](陈设尺寸清单.md)；当前角色尺寸以 `scripts/player.gd` 为准。

## 目录

| 路径 | 内容 |
| --- | --- |
| `scenes/` | 住宅家具、设备、狗窝、彩蛋开关和香蕉等可复用场景 |
| `models/`、`meshes/` | 导出 GLB 与 Godot 网格 |
| `materials/`、`textures/` | 材质、着色器和贴图 |
| `authoring/` | Blender 建模源文件 |
| `quest_props/` | 每日任务道具、印刷贴图和生命周期工具 |
| `basement/` | 医学实验室模型、材质与笼门组件 |
| `villa_layout.json` | 当前住宅家具实例清单 |
| `previews/` | 资产库参考图；当前游戏截图以根目录 README 为准 |

实体家具采用分部件碰撞，保留桌下、床下等可行空间。台面小摆件和装饰一般不额外阻挡通行。房屋中的门、洗衣机、水龙头、烤箱、电脑、电视及任务家具由游戏控制器接入交互，不能只根据独立预览判断其游戏行为。

材质使用方式见 [材质与房间风格](材质与房间风格.md)。当前房屋和生成配置维护方式见 [开发说明](../docs/DEVELOPMENT.md)。修改场景中的位置时，也要考虑任务脚本的绑定与交互点；重建地图前先保留手工布局。
